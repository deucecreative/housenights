# Wallet badges

Drop Apple's official "Add to Apple Wallet" badge here as
`apple-add-to-wallet.svg` (or `.png`) to host it locally instead of
loading from `developer.apple.com`.

Source: https://developer.apple.com/wallet/add-to-apple-wallet-guidelines/

Until a local copy is committed, the `AttendeeTicket` component falls
back to the badge image hosted on Apple's developer site.
